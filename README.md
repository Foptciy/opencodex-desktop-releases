# OpenCodex Desktop downloads

Public Windows installers and release notes for OpenCodex Desktop.

**[Download the latest release](https://github.com/Foptciy/opencodex-desktop-releases/releases/latest)**

- **Setup** installs the application and supports in-app updates.
- **Portable** runs without installation.
- Version 0.2.4 and later check this public update feed without requiring GitHub sign-in.

OpenCodex Desktop is an independent client for the open-source Codex agent runtime. It is not the official OpenAI Codex desktop application and is not affiliated with or endorsed by OpenAI.
